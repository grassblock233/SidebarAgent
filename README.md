<h1 align="center">SidebarAgent</h1>

一个 Chrome / Edge Manifest V3 插件。选中网页文字后，可以通过右键菜单把内容送入侧边栏，并使用所选 AI 提供商进行解释、总结、翻译和连续追问。



> *由于当前尚未上架Chrome插件商店，使用crx安装会提示“此扩展不是来自任何已知来源”，故提供下面两种安装方式*

## 安装(推荐)

1. 下载仓库所有文件，打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目的 `SidebarAgent` 目录。
5. 点击扩展图标打开侧边栏，再点击底部输入栏的设置按钮。
6. 选择 AI 提供商，填写 API Key，获取或手动填写模型后保存并设为当前提供商。

## 安装(使用crx)

1.下载release中的crx文件。
2.更改后缀名为.zip，拖动入浏览器扩展程序界面。

## 使用

1. 在普通网页中选中一段文字。
2. 点击右键，选择“用 SidebarAgent 分析所选内容”。
3. 在侧边栏中使用快捷操作，或输入自己的问题。
4. 也可以点击输入栏下方的“读取当前屏幕文字”图标，将当前网页视口内的 DOM 文字作为新来源。

## 侧边栏交互

- 发送按钮在生成开始后会原位切换为停止按钮。
- 来源文字默认显示一行，超出部分以省略号隐藏，点击“展开”后显示其余内容。
- 来源面板按文字量自然增高，最多占侧边栏高度的一半；超长内容在来源区域内部滚动。
- 输入栏固定在侧边栏底部，长输入在输入框内部滚动，不改变布局高度。
- 来源区和快捷操作固定在顶部，文本增加时只滚动中间的聊天区域。
- 输入框下方可直接从当前提供商已缓存的模型列表中切换模型；手动模型仍在设置页修改。
- 清除对话和设置入口位于输入栏右下方。
- “读取当前屏幕文字”只在用户点击后读取当前视口中的 DOM 文字，不使用截图或 OCR。
- 读取结果会生成用于来源预览的纯文本，并向 AI 提供仅含可见内容的精简 HTML，以保留标题、列表、表格、引用和代码结构。
- 首次读取某个网站时，浏览器会请求该网站的访问权限；授权仅针对对应域名。
- AI 回复支持 Markdown 表格，表格过宽时可在消息内横向滚动。

## 提供商与模型配置

- 内置支持 DeepSeek、千问国内站、千问国际站和火山方舟。
- 可以保存多个自定义 OpenAI Chat Completions 兼容提供商，并选择一个作为当前提供商。
- 自定义提供商使用 Bearer Token 鉴权，需提供 Base URL、聊天接口路径，并可选提供模型列表接口路径。
- 远程自定义接口必须使用 HTTPS；本机 `localhost` 和 `127.0.0.1` 可以使用 HTTP。
- 模型列表只在用户点击“连接并获取模型”或“刷新模型列表”时更新，不会发送额外测试聊天请求。
- 不支持模型发现或获取失败时，可以切换到“手动输入”，填写模型 ID；火山方舟也可填写推理接入点 ID。
- 模型列表和各提供商配置缓存在 `chrome.storage.local` 中。切换提供商或模型不会清除当前对话，下一次请求使用新配置。
- 旧版 DeepSeek API Key 配置会自动迁移到 `deepseek-chat`，旧存储键会保留，便于回退。

## 数据与安全

- API Key、模型列表和当前模型保存在 `chrome.storage.local`，不会写入项目文件。
- 当前选区和对话保存在 `chrome.storage.session`，浏览器会话结束后清除。
- 选中文字、网页标题、网址和对话内容会直接发送给当前选择的 AI 提供商。
- 自定义提供商首次使用某个域名时，浏览器会显示域名访问权限提示；插件只申请该域名的权限。
- 插件不使用分析服务或远程脚本。
- 浏览器本地存储不是系统级加密保险箱，本项目定位为个人使用工具。

## 当前限制

- 自定义提供商必须兼容 OpenAI 的 `/chat/completions` 流式 SSE 响应，并使用 Bearer Token 鉴权。
- 不具备实时联网搜索能力。
- 单次选区最多保留 12,000 个字符。
- 当前视口的精简 HTML 最多保留 24,000 个字符，并在完整标签边界内截取。
- 只读取用户主动选中的文字，不读取网页全文或 PDF 文档结构。
- 浏览器内部页面、扩展商店、图片、Canvas 和视频画面中的文字无法通过视口文字读取功能获取。
