# DeepSeek 侧边栏

一个 Chrome / Edge Manifest V3 插件。选中网页文字后，可以通过右键菜单把内容送入侧边栏，并使用 DeepSeek 进行解释、总结、翻译和连续追问。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目的 `deepseek-sidepanel` 目录。
5. 点击扩展图标打开侧边栏，再点击底部输入栏的设置按钮。
6. 填写 DeepSeek API Key，点击“连接并获取模型”，选择模型后保存配置。

## 使用

1. 在普通网页中选中一段文字。
2. 点击右键，选择“用 DeepSeek 分析所选内容”。
3. 在侧边栏中使用快捷操作，或输入自己的问题。

## 侧边栏交互

- 发送按钮在生成开始后会原位切换为停止按钮。
- 来源文字保持紧凑显示，鼠标悬停或键盘聚焦时会浮动展开。
- 点击来源区域的图钉可以固定展开；输入框获得焦点后会自动取消固定。
- 输入栏固定在侧边栏底部，长输入在输入框内部滚动，不改变布局高度。
- 来源区和快捷操作固定在顶部，文本增加时只滚动中间的聊天区域。
- 输入框下方显示当前模型，点击模型名称可以打开设置页。
- 清除对话和设置入口位于输入栏右下方。

## 模型配置

- 模型列表通过 DeepSeek 的 `/models` 接口获取，不会额外发送测试聊天请求。
- 模型列表和当前选择缓存在 `chrome.storage.local` 中。
- 模型列表只在用户点击“连接并获取模型”或“刷新模型列表”时更新。
- 如果已选择的模型不再可用，插件会要求重新选择，不会静默切换。
- 旧版 API Key 配置会自动迁移到 `deepseek-chat`，之后可以手动刷新完整列表。

## 本地验证

项目没有运行时依赖，也不需要构建。

```bash
npm run check
npm test
```

## 数据与安全

- API Key、模型列表和当前模型保存在 `chrome.storage.local`，不会写入项目文件。
- 当前选区和对话保存在 `chrome.storage.session`，浏览器会话结束后清除。
- 选中文字、网页标题、网址和对话内容会直接发送给 DeepSeek。
- 插件不使用分析服务、远程脚本或其他第三方接口。
- 浏览器本地存储不是系统级加密保险箱，本项目定位为个人使用工具。

## 当前限制

- 只支持 DeepSeek API 返回的模型，不支持其他 AI 服务商。
- 不具备实时联网搜索能力。
- 单次选区最多保留 12,000 个字符。
- 只读取用户主动选中的文字，不读取网页全文或 PDF 文档结构。
